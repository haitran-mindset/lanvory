# Design system

The supplied image defines the desktop visual direction. Use a graphite shell, subtle dotted background, green status and action accents, thin borders and readable monospaced labels. The identity summary and device list share the main area at desktop widths. Stack them when the window is narrow.

Show discovered devices, trusted devices, shared services and active transfers using local daemon data. Show a dash when a value is unavailable. Make unavailable features identifiable and use meaningful empty, loading and recovery states. Use focus indicators and text labels alongside status colors. Keep the product wordmark and illustration original.

## Desktop reference mapping

| Reference area | Lanvory desktop |
| --- | --- |

Only the page content scrolls. At narrow widths the hero and device list stack, and the tiles use two columns. Terminal and remote command execution are outside the current plan.
