# Tasks

CI-01 also tracks existing Linux core and macOS x64 regression coverage outside the MVP acceptance gate. Evidence is recorded per criterion under [§67](PROJECT_SPEC.md#67-definition-of-done). `DONE` rows cover their locally scoped acceptance criteria. Physical and release gates are tracked below as separate tasks. See [HANDOFF.md](HANDOFF.md#open-verification-gates) for available evidence and prerequisites.
